⭐ ব্যাকেন্ড ভার্শন ২ — আলাদা আলাদা ফাইলে (Task API)

ভার্শন ১ এ সব কোড index.js এ ছিল। বড় প্রজেক্টে কোড ভাগ করে রাখা হয় — প্রতিটি ফাইলের একটাই দায়িত্ব। এখানে একটি সিম্পল Task API (লগইন ইউজার নিজের টাস্ক যোগ/দেখা/টগল/ডিলিট করবে) বানিয়ে পুরো কাঠামো শিখব।

কোন ফোল্ডারের কাজ কী?

ফোল্ডার/ফাইলদায়িত্ব
index.jsEntry point — DB কানেক্ট করে সার্ভার চালু
app.jsExpress অ্যাপ, middleware ও রুট যুক্ত করা
config/MongoDB কানেকশন
routes/URL → কোন controller চলবে
controllers/আসল লজিক (DB তে কাজ, res পাঠানো)
models/Collection এর হেল্পার (ডাটা কাঠামো)
middlewares/verifyToken ইত্যাদি মাঝপথের চেক
রিকোয়েস্টের পথ: index.js → app.js → routes → middleware (verifyToken) → controller → model → MongoDB → response

ধাপ ১: ফোল্ডার ও প্যাকেজ

ধাপ ২: config/db.js — ডাটাবেজ কানেকশন

ধাপ ৩: models/ — Collection হেল্পার

ধাপ ৪: middlewares/verifyToken.js

ধাপ ৫: controllers/ — আসল লজিক

ধাপ ৬: routes/ — URL ম্যাপিং

ধাপ ৭: app.js ও index.js

ধাপ ৮: টেস্ট করো (Postman/Thunder Client বা curl)
