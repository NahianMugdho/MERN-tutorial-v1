সম্পূর্ণ টিউটোরিয়ালের সামারি

এই গাইডে React (Vite) + Tailwind + DaisyUI ফ্রন্টেন্ড, Node/Express + MongoDB ব্যাকেন্ড, Firebase Auth + JWT দিয়ে সিকিউরিটি এবং Vercel / Firebase Hosting এ ডেপ্লয় শেখানো হয়েছে। নিচের ক্রমে এগোলে সবচেয়ে ভালো।

Access/Refresh token, Rotation, Revoke, Redis, Rate limit, Argon2, 2FA, Cache 🔒 সিকিউর মিনি প্রজেক্ট

টার্মিনাল সিমুলেটর কীভাবে ব্যবহার করবে

১. সেটআপ, ব্যাকেন্ড ও ডেপ্লয় পেজের নিচে "প্র্যাকটিস" টার্মিনাল আছে। উপরের টাস্ক লিস্টে ক্লিক করলে কমান্ড ইনপুটে বসে যাবে, Enter চাপলেই রান হবে।
২. কমান্ড ঠিকমতো চালালে টাস্কে ✅ পড়বে।
৩. help লিখলে সাপোর্টেড কমান্ড দেখাবে; ↑ / ↓ দিয়ে আগের কমান্ড ফেরত আনা যায়।
৪. ls, cd, mkdir, cat কাজ করে। npm install ঠিক ফোল্ডারে না চালালে আসল টার্মিনালের মতোই এরর দেখাবে।
এটি শুধু সিমুলেটর — আসলে কিছু ইনস্টল হয় না। আসল প্র্যাকটিস নিজের কম্পিউটারে করো।
