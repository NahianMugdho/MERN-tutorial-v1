🔒 সিকিউর মিনি প্রজেক্ট: secure-api

প্রজেক্টটা কিসের ওপর?
একটা ছোট ব্যাকেন্ড যেখানে অ্যাডভান্সড পেজের সবকিছু একসাথে চলে: Argon2 পাসওয়ার্ড, access+refresh টোকেন (rotation ও revoke), 2FA, Redis, rate limit ও API cache। ডাটা: users ও tasks। ফ্রন্টেন্ড ছাড়াই curl দিয়ে পুরোটা টেস্ট করা যায়।
ফিচারকোন ফাইলে
Argon2utils/password.js → auth.controller (register/login)
Access/Refresh, Rotation, Revokeutils/tokens.js, verifyAccess.js, refresh/logout কন্ট্রোলার
2FAutils/twofa.js, setup/enable/verify2fa
Rate limitmiddlewares/rateLimit.js (app.js ও auth.routes এ)
Redisconfig/redis.js — সবার নিচে
API Cachemiddlewares/cache.js → task.routes/controller

🎬 ইন্টারেক্টিভ: পুরো প্রজেক্ট ব্যবহারের ক্রম

স্ট্রাকচার ও ক্রম

ক্রমফাইলকাজ
1package.jsonসব প্যাকেজের তালিকা: argon2, ioredis, rate-limit, otplib ইত্যাদি। mkdir secure-api && cd secure-api && npm init -y করে নিচের প্যাকেজ ইনস্টল করলেই হবে।
2.env৩টা আলাদা সিক্রেট (access, refresh, temp-2FA) ও Redis URL।
3config/db.js , config/redis.jsMongoDB ও Redis এ সংযোগ।
4models/user.model.js , models/task.model.jsusers ও tasks collection হেল্পার।
5utils/password.js , utils/twofa.js , utils/tokens.jsপাসওয়ার্ড হ্যাশ, TOTP, টোকেন তৈরি/rotation/revoke — অ্যাপের হৃদয়।
6middlewares/verifyAccess.js , middlewares/rateLimit.js , middlewares/cache.jsটোকেন যাচাই, রেট-লিমিট, API ক্যাশ।
7controllers/auth.controller.js , controllers/task.controller.jsauth: register, login, 2FA, refresh, logout; task: cache-সহ টাস্ক।
8routes/auth.routes.js , routes/task.routes.jsকোন URL এ কোন middleware + controller; লগইন রুটে loginLimiter।
9app.js , index.jsapp.js: CORS(credentials), cookieParser, globalLimiter, রুট; index.js: DB কানেক্ট → সার্ভার চালু।
10src/utils/axiosSecure.jsReact এ access token মেমরিতে + অটো refresh interceptor। লগইনের পর setAccessToken(res.data.accessToken) ডাকো।

ধাপ 1: প্রজেক্ট ও প্যাকেজ

কাজ: সব প্যাকেজের তালিকা: argon2, ioredis, rate-limit, otplib ইত্যাদি। mkdir secure-api && cd secure-api && npm init -y করে নিচের প্যাকেজ ইনস্টল করলেই হবে।
ক্রম কেন: ভিত্তি।

ধাপ 2: সিক্রেট

কাজ: ৩টা আলাদা সিক্রেট (access, refresh, temp-2FA) ও Redis URL।
ক্রম কেন: পরের সব ফাইল এগুলো পড়ে।

ধাপ 3: ডাটাবেজ ও Redis কানেকশন

কাজ: MongoDB ও Redis এ সংযোগ।
ক্রম কেন: models, tokens, rateLimit, cache সবাই এগুলো ব্যবহার করে।

ধাপ 4: models

কাজ: users ও tasks collection হেল্পার।
ক্রম কেন: controller এ লাগবে।

ধাপ 5: utils: Argon2, 2FA, Tokens

কাজ: পাসওয়ার্ড হ্যাশ, TOTP, টোকেন তৈরি/rotation/revoke — অ্যাপের হৃদয়।
ক্রম কেন: controller এগুলো সরাসরি ডাকে।

ধাপ 6: middlewares

কাজ: টোকেন যাচাই, রেট-লিমিট, API ক্যাশ।
ক্রম কেন: routes এ বসানোর জন্য তৈরি থাকতে হবে।

ধাপ 7: controllers

কাজ: auth: register, login, 2FA, refresh, logout; task: cache-সহ টাস্ক।
ক্রম কেন: utils ও models ব্যবহার করে বলে এদের পরে।

ধাপ 8: routes

কাজ: কোন URL এ কোন middleware + controller; লগইন রুটে loginLimiter।
ক্রম কেন: controller তৈরির পর।

ধাপ 9: app.js ও index.js

কাজ: app.js: CORS(credentials), cookieParser, globalLimiter, রুট; index.js: DB কানেক্ট → সার্ভার চালু।
ক্রম কেন: সবার শেষে।

ধাপ 10: ফ্রন্টেন্ড (ঐচ্ছিক)

কাজ: React এ access token মেমরিতে + অটো refresh interceptor। লগইনের পর setAccessToken(res.data.accessToken) ডাকো।
ক্রম কেন: API চালু হওয়ার পর জোড়ো।

✅ টেস্ট করো (curl)

Redis দেখতে: docker exec -it redis redis-cli → KEYS * (rt:, rts:, bl:, cache:, rl: key গুলো দেখা যাবে)।
