🚀 প্রজেক্ট: TaskFlow — ব্যক্তিগত টাস্ক ম্যানেজার

প্রজেক্টটা কিসের ওপর?
TaskFlow হলো একটি ছোট কিন্তু সম্পূর্ণ MERN অ্যাপ, যেখানে প্রতিটি ইউজার Firebase দিয়ে রেজিস্টার/লগইন করে নিজের টাস্ক যোগ করে, শেষ হলে টিক দেয়, আর ডিলিট করে। টাস্কগুলো MongoDB তে জমা থাকে এবং JWT টোকেনের কারণে প্রতিজন শুধু নিজের টাস্কই দেখতে ও বদলাতে পারে।
ফিচারকোথায় শিখবে
Email/Google অথেনটিকেশনFirebase, AuthContext, Login, Register
সুরক্ষিত পেজPrivateRoute, Dashboard
টোকেন-ভিত্তিক APIJWT, verifyToken, axiosSecure
টাস্ক CRUD (যোগ/দেখা/টগল/ডিলিট)task.routes → task.controller → MongoDB
আলাদা ফাইলে ব্যাকেন্ড (ভার্শন ২)config, models, controllers, routes, middlewares
তথ্যের যাত্রা: Register → Firebase অ্যাকাউন্ট + MongoDB users → Login → Firebase ইউজার → JWT আনা → Dashboard → axiosSecure + টোকেন → /api/tasks → verifyToken → controller → MongoDB → UI আপডেট
⚠️ আগে ব্যাকেন্ড বানিয়ে চালাও, তারপর ফ্রন্টেন্ড — নইলে লগইনের পর JWT আনতে গিয়ে এরর আসবে। নিচে ফ্রন্টেন্ড আগে দেখানো হয়েছে পড়ার সুবিধায়; করার ক্রম: ব্যাকেন্ড (১-১০) → ফ্রন্টেন্ড (১-১৩)।

📦 ব্যাকেন্ড — task-api (ভার্শন ২)

ধাপ 1: package.json

কাজ: প্যাকেজ তালিকা ও scripts। npm init -y ও npm install দিলে নিজে তৈরি হয়; এখানে শুধু দেখার জন্য।
ক্রম কেন: প্রথমে — প্রজেক্ট ও প্যাকেজ ছাড়া কিছুই চলবে না।

ধাপ 2: env ও gitignore

কাজ: সিক্রেট কী রাখে ও গিটে যাওয়া আটকায়।
ক্রম কেন: আগে — config/db.js ও verifyToken এগুলো পড়ে।

ধাপ 3: config/db.js

কাজ: MongoDB তে কানেক্ট করে এবং getDB() দেয়।

ধাপ 4: models/

কাজ: users ও tasks collection এর হেল্পার।

ধাপ 5: middlewares/verifyToken.js

কাজ: JWT যাচাই করে; ঠিক হলে req.decoded এ email রাখে।

ধাপ 6: controllers/

কাজ: আসল লজিক: টোকেন তৈরি, ইউজার সেভ, টাস্কের CRUD।

ধাপ 7: routes/

কাজ: URL কে controller এর সাথে জোড়ে (task রুট verifyToken দিয়ে সুরক্ষিত)।
ক্রম কেন: controllers তৈরির পরে।

ধাপ 8: app.js

কাজ: Express কনফিগ: CORS, JSON, সব রুট যুক্ত করা, ৪০৪/৫০০ হ্যান্ডলার।
ক্রম কেন: routes এর পরে।

ধাপ 9: index.js

কাজ: env লোড, DB কানেক্ট, তারপর সার্ভার চালু।
ক্রম কেন: app.js এর পরে — শেষ কোড ফাইল।

ধাপ 10: vercel.json

কাজ: Vercel এ ডেপ্লয়ের কনফিগ (JSON, তাই কমেন্ট নেই)।
ক্রম কেন: ডেপ্লয়ের আগে।
