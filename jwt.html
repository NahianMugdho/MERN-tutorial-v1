৬. JWT Token — কীভাবে কাজ করে

JWT (JSON Web Token) একটি compact, self-contained token যা ইউজারের identity প্রমাণ করে। এটি তিন অংশে বিভক্ত:

অংশকী থাকেউদাহরণ
HeaderAlgorithm ও Token type{ alg: HS256, typ: JWT }
PayloadUser data (claims){ email, iat, exp }
SignatureVerify করতে ব্যবহার হয়HMACSHA256(header.payload, secret)

JWT Flow — ধাপে ধাপে

১. User login করলে backend এর /jwt এ email যায়
২. Backend token sign করে পাঠায়
৩. Frontend localStorage এ সেভ করে
৪. Protected API call এ Authorization: Bearer <token> যায়
৫. verifyToken middleware verify করে
৬. Valid হলে data, নয়তো 401/403
স্ট্যাটাসঅর্থ
401Token/Authorization header নেই
403Token ভুল বা মেয়াদোত্তীর্ণ
⚠️ JWT_SECRET কখনো frontend এ বা GitHub এ রাখবে না। শুধু backend এর env এ।
