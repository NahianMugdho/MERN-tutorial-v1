🔌 ফ্রন্টেন্ড ও ব্যাকেন্ড কীভাবে সংযুক্ত হয়

ফ্রন্টেন্ড (React, ব্রাউজারে চলে) আর ব্যাকেন্ড (Express, সার্ভারে চলে) আলাদা প্রোগ্রাম। তারা কথা বলে HTTP রিকোয়েস্ট দিয়ে — React axios দিয়ে URL এ রিকোয়েস্ট পাঠায়, Express সেই URL ধরে উত্তর দেয়।

localhost:5173 (React) ⇄ localhost:5000 (Express) ⇄ MongoDB Atlas

ইন্টারেক্টিভ: একটি রিকোয়েস্টের যাত্রা

▶ বাটনে ক্লিক করে ধাপগুলো দেখো

সংযোগের ৪টি মূল জিনিস

#ফ্রন্টেন্ডেব্যাকেন্ডে
১. ঠিকানাVITE_API_URL=http://localhost:5000PORT=5000 এ listen
২. অনুমতি (CORS)frontend এর origin http://localhost:5173cors({ origin: [ ... ] }) এ ওই origin
৩. পথ (route)axiosSecure.get('/api/tasks')app.use('/api/tasks', ...)
৪. পরিচয় (JWT)localStorage এর টোকেন → Bearer হেডারverifyToken যাচাই
দুই পাশের নাম মিলতে হবে: ফ্রন্টেন্ডের URL পাথ = ব্যাকেন্ডের route পথ, আর HTTP মেথড (GET/POST/PATCH/DELETE) একই হতে হবে।

Task প্রজেক্টের ফ্রন্টেন্ড অংশ

ধরে নিচ্ছি ফ্রন্টেন্ড পেজের AuthContext, PrivateRoute ও axiosSecure তৈরি আছে। শুধু VITE_API_URL=http://localhost:5000 আর baseURL ঠিক রাখো।
