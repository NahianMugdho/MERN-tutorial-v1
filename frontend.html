৫. Firebase Authentication

Console সেটআপ: নতুন Project → Authentication → Email/Password ও Google enable → Project Settings থেকে SDK config কপি → Authorized domains এ production domain যোগ।
💡 JWT টোকেন onAuthStateChanged এর ভেতরে নেওয়া best practice — Firebase login এর পরপরই ইউজার নিশ্চিত থাকে।
